    Interface QueryPlanConfigs

    Complete query plan configs — all intermediate data needed by the pipeline engine.

    Contains the source plan, join plans, calculated columns, filters, aggregates, sorts, subtotal config, column map, and source catalog. The pipeline engine's stage functions consume these configs to build and execute temp tables sequentially.
