## Contributing to TableFlip

Thanks for helping improve TableFlip.

### Getting started

1. Fork the repository
2. Create a feature/fix branch from `main`
3. Make focused changes with clear commit messages
4. Open a pull request with:
   - what changed
   - why it changed
   - screenshots/GIFs for UI changes (if applicable)

### Guidelines

- Keep changes small and purposeful
- Preserve existing behavior unless intentionally changing it
- Prefer readable code over clever code
- Update docs when behavior or setup changes

### Pull request checklist

- [ ] Change is scoped and tested manually
- [ ] README/docs updated as needed
- [ ] No unrelated file churn
- [ ] Third-party/license implications considered

### Reporting bugs

Please include:

- steps to reproduce
- expected behavior
- actual behavior
- sample file shape (sanitized)
- browser + OS
