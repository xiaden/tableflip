# ASR-0002

**Priority:** 2  
**Status:** Active  
**Created:** 2026-06-14  
**Updated:** 2026-06-14  

## Requirement

All user-facing language must be accessible to a non-technical audience with zero domain knowledge. The test is whether a non-technical person — someone who was handed the application and told to combine reports — can understand every label, button, tooltip, error message, toast, and export prompt without needing explanation.

**Scope:** Every string the user sees. Labels, buttons, tooltips, error messages, toasts, export filenames, prompts, confirmation dialogs. If the user can see it, it must pass.

**Prohibited:**
- Technical jargon: "JOIN", "SQL", "Excel", "JSON", "schema", "column alias", "aggregate", "query", "WHERE clause", "GROUP BY"
- Spreadsheet/programming terms: "cell", "row", "column" (acceptable only when unavoidable — prefer "item", "entry", "field")
- Abbreviations and acronyms the user didn't bring with them

**Required:**
- Plain-language alternatives for every concept: joins → "combining" or "looking up and matching", detail bands → "related details"
- Error messages must say what went wrong in terms the user understands — never expose internal error strings
- File operations use consumer-friendly naming (current `.rcjson` extension is under review; `.flip` proposed)

**Naming approach:** Ad-hoc, user-tested, revised as needed. There is no canonical mapping — terms are expected to change through iteration. Developers should not assume a name is final. If you're adding a new feature, pick the plainest name you can think of; it will be renamed later.

**Enforcement:** No automated tooling. Tested by putting non-technical users in front of the application. If they're confused, it's wrong.

## Notes

The current UI is visually cluttered and confusing for non-technical users. This ASR establishes the language standard; a separate UI clarity effort (visual layout, information hierarchy) is implied but not specified here.

File extension change (.rcjson → .flip) is noted as a potential rename but not mandated by this ASR.
