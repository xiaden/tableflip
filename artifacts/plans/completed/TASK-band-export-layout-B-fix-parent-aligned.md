# Task: Fix Band Export Layout — Parent-Column-Aligned

## Problem Statement

The current band export layout in `buildBandColumnLayout()` and `applyBandGroup()` produces a WRONG compact `[match + band cols]` layout that removes parent columns. The sheet header shows band column names instead of original parent column names, and parent rows are collapsed to just the match value with empty band columns.

**Correct behavior** (per revised DD v2):
- Sheet header = parent column labels (e.g., `[Order ID, Company, Amount]`)
- Parent rows pass through with ALL parent columns populated (kind 5)
- Band section headers: col 0 = match value, cols 1+ = band column display names (relabeling parent column positions)
- Band data rows: col 0 = empty, cols 1+ = band column values (in parent column positions)
- Sheet width = max(parent cols, 1 + max band cols) — extra columns appended if band is wider

**Example:**
```
| Order ID | Company  | Amount |    ← parent columns as header (unchanged)
| ORD-1    | Acme     | 100    |    ← parent row (all columns populated, kind 5)
| ORD-1    | Quantity | Price  |    ← band section header (cols 1+ relabeled, kind 4)
|          | 5        | 10.00  |    ← band data (col 0 empty, cols 1+ populated, kind 0)
```

Fixes issues from Plan A (TASK-band-export-layout-A) which implemented the wrong layout.
