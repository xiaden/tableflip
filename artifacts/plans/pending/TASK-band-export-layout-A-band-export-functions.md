# Task: Band Export Layout Functions + Integration + Styling + Tests

## Problem Statement

The current XLSX/CSV export for detail-band reports produces a wide, sparse sheet with the superset of all parent and band columns, null-padded where columns don't apply. This plan creates three new pure functions in `export.ts` that transform the engine's wide-format rows into a compact "match column + band columns" layout, integrates this band layout path into `exportAs()`, adds row kind 5 styling for band parent rows in `styleExportSheet()`, and adds ~32 tests covering all new code. All changes are confined to `SRC/preact/ui/export.ts` and `SRC/preact/tests/ui/export-bands.test.ts`. No engine, query, catalog, or UI component changes.
